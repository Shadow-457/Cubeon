Mode: **populated** - 30/30 captured by `tools/ux_capture.py`.

Review by eye or feed the PNGs to a vision model against a UX rubric. `manifest.json` has the machine-readable list.

- `02_tab_mods.png` - Mods tab default: content type tabs, search, browse grid density.
- `03_tab_modpacks.png` - Modpacks browse: pack rows with install affordances.
- `04_tab_chat.png` - Chat with no conversation: empty-state copy and the friends rail.
- `05_tab_profile.png` - Cosmetics: skin pane, live preview, installed cards.
