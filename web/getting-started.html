Getting started

One download, one name, one Play button. This page covers the file to pick, what happens on the first run, and the handful of settings that are worth knowing about.

Step one

What to download

Everything is on the download page, and every build is free with no account attached. Pick the file that matches your computer:

  • Windows - setup file. Double-click it, click through the installer, and launch Cubeon from the Start menu. This is the easiest option for most people.
  • Windows - portable ZIP. Extract the whole folder somewhere you can write to (your user folder or another drive, not inside Program Files), then run Cubeon.exe from inside it. Keep the folder's files together: moving just the .exe will break it.
  • Linux - installer or package. Use whichever your distribution handles best. If you take the AppImage, mark it executable once and run it.
chmod +x Cubeon-x86_64.AppImage
./Cubeon-x86_64.AppImage

There is no Mac build yet. When there is one, it will be on the download page.

What the computer needs

  • Windows 10 or 11, or a modern 64-bit Linux.
  • At least 4 GB of system memory for vanilla Minecraft; 8 GB or more is comfortable once you add mods.
  • A graphics card that can already run Minecraft, and a little disk space per installed version.

You do not need a Minecraft account, an email address, Java, or Python. Cubeon is a self-contained app, and it fetches the game files and a Java runtime itself.

If Windows warns you about the file

Small independent apps are not signed by a big publisher, so Windows SmartScreen shows a warning the first time. Choose More info, then Run anyway (or Keep if your browser asks first). Only do that for a file you downloaded from the download page - and never turn off Windows security as a whole to get an app running.

Your first launch

Cubeon opens on the Play tab. Three things happen, in this order:

  1. Pick a name. Three to sixteen characters, no password, no email. The name is how friends find you, and names are first come, first served - so pick the one you want now rather than later.
  2. Choose a Minecraft version from the version picker. Leave the loader on Vanilla unless you already know you need mods.
  3. Press Play. The first launch downloads the game itself, so it takes a few minutes depending on your connection. A progress bar shows what is being fetched, and the button turns into Cancel while it works.

Cancelling during that first download is safe: nothing is half-installed, and pressing Play again picks up where it stopped.

Cubeon uses an offline profile

There is no Microsoft or Mojang sign-in. That is what makes "pick a name and play" possible, but it also means servers that require a real Minecraft account will reject you - see offline names and premium servers.

Versions and loaders

A "version" in Cubeon is a Minecraft release plus, optionally, a mod loader. The launcher can install these loaders for you:

  • Vanilla - the plain game. Resource packs work; mods and shaders do not.
  • Fabric and Quilt - the usual choice for performance mods, cosmetic mods and most modern packs.
  • Forge and NeoForge - needed by the mods and older packs that were built for them.

The important rule: a mod only runs on the loader and the Minecraft version it was built for. A Fabric mod does not work because a Forge version is installed, and a 1.20.1 mod does not work on 1.21. The mods guide starts with that check for a reason.

Install as many versions as you like. Each one is downloaded once and then starts quickly.

Instances

An instance is one version in its own folder with its own settings. Your worlds, video settings, keybinds and server list belong to the instance you launch - a redstone test world and a shader-heavy world can live side by side without fighting over options.txt.

  • Play card - shows the instance you have selected and its loader. Folder, Rename and Delete live here.
  • The pencil - opens the icon picker: 20 blocks and 20 mob heads. The icon is saved per instance; clicking the card still selects it.
  • Shared content - installed mods, resource packs and shaders are kept once and shared by every instance, so a mod you add does not have to be added twice.

Deleting an instance does not delete its world folder. If you want the world gone too, remove that folder yourself - inside an instance shows where it is.

Java and memory

Java is handled for you

Cubeon uses a Java it finds on your computer when that Java is new enough for the version you picked, and otherwise downloads a free one for you. You only need to touch this if you want a specific Java build.

In that case open Settings > Java and point it at the java executable. Use a 64-bit build: 1.18 to 1.20.4 want Java 17, 1.20.5 and newer want Java 21, and the 26.x versions want Java 25. A path to a 32-bit Java, or to an old Java 8, is the most common reason a launch fails after someone changes this by hand.

Memory

Cubeon starts you at 4 GB, which is right for vanilla and light modding. Raise it to 6-8 GB for a heavy modpack. Going much higher on a 4 GB or 8 GB machine makes things worse, not better: the operating system and the rest of the game still need memory of their own.

In Settings > Performance > Java, expand Cubeon's default flags to see exactly what will be passed to the game, including which options were skipped on your hardware. Custom flags are added after the defaults.

FPS boost

FPS boost is on by default. When you launch, it installs Sodium and five companion mods (Lithium, ImmediatelyFast, Entity Culling, FerriteCore and More Culling) into that profile and sets the graphics options that cost frames to their fast values.

Turning it off restores vanilla graphics on the next launch - the switch is in the Play menu and it always says which way it is set. The benchmarks page has the measured numbers, and the caveats next to them.

Already boosted and still stuttering?

Lower your render distance first. It is almost always the single biggest setting, and it costs far less than it looks. Slow or stuttering has the rest.

Settings worth knowing

Settings sit inside the account panel, in a short rail down the left. The ones people actually change:

  • Language - 22 languages, searchable by native name, English name or code. Arabic, Urdu, Persian and Pashto switch the whole launcher to right-to-left. A language change applies after a restart, and detailed messages without a translation fall back to English.
  • Custom title bar - on by default on Windows and Linux. Turn it off if your window manager draws its own title bar.
  • Notifications - System > Notifications > Chat messages controls incoming message alerts. Open conversations do not alert you, and old history never does.
  • Backups - save and restore your launcher settings and history. Backups explains what is covered.
  • Screenshots - its own section, with the gallery of what you have captured in game.
  • Import - scan an old .minecraft folder and pick up mods, packs and worlds from it. Packs and worlds from an old setup covers that.

Updating

When a new version is out, Cubeon tells you and points at the download page. It does not replace itself while it is running.

  1. Download the new build.
  2. Close Cubeon completely - including the tray icon if your desktop keeps one.
  3. Run the new installer, or replace the contents of your portable folder.

Your name, skins, worlds and installed content are not touched by an update: they live in your user folder, not in the app folder (where things live).

Settings > Updates also lets you pick the update channel. Stable gets releases; beta gets the test builds as well.
