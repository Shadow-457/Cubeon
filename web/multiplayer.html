Playing together

Add friends by name, open a server from your own computer, and give people an address they can type. This page also has the list to work through when someone cannot get in.

Friends and chat

Friend requests go by Cubeon name, not by Minecraft account - there is no email to search for and no code to swap. Type the name in the friends list and send the request.

  • The other person must have opened Cubeon at least once. Before that, the name does not exist yet.
  • Names are first come, first served. If the one you want is taken, it is taken.
  • Once you are friends, the launcher shows who is online and which Minecraft version they are playing, and keeps your conversation.
  • In game, Cubeon players are marked in Minecraft's own player list - hold Tab.

Chat is marked BETA in the launcher. Messages are kept for the conversation, and an open conversation does not fire an incoming alert at you (you are already reading it).

Hosting a world

Cubeon can run a real Minecraft server on your own computer and give it a public address, so your friends do not need to change anything on their end and nobody pays for hosting.

  1. Open Servers and pick the Minecraft version to host.
  2. Press Install for that version if it is not there yet.
  3. Start it. Once it is up, the tab shows the public address - copy that and send it to your friends.
  4. Optionally set a join password. Anyone without it does not get in, even with the address.

Three things to know before you promise anyone a game:

  • Your computer is the server. It has to stay on and awake, and Cubeon (or at least the server) has to keep running. A sleeping laptop is a dead server.
  • First start is slow. The server generates its world before it accepts players.
  • The tunnel can be blocked. Some networks and firewalls interrupt the shared address. If it never comes up, try a different network, or ask on the Discord with what the console says.

Console, Plugins and Settings sit under the server tab. Settings is where RAM lives - the default is fine for a few friends; raise it if the server is struggling, not by default.

Joining a server

In Minecraft, open Multiplayer > Add Server, paste the address, and join. The address from Cubeon already includes the port, so paste the whole thing rather than splitting it up.

If the address came with a join password, you will be asked for it on the way in.

To join, three things have to line up:

  • The Minecraft version - the same one the server runs.
  • The loader - a Fabric server wants a Fabric client; vanilla wants vanilla.
  • The mods - if the server requires mods, install the same ones. A vanilla client on a modded server is a mismatch even when the Minecraft version matches.

The launcher shows the version a friend is playing, which is the fastest way to find out why you cannot meet in the middle.

Whitelist and password

Two different locks, and they fail differently:

  • Join password - set in Servers, checked before you reach the world. Wrong or missing password means the connection is refused.
  • Whitelist - a list of names allowed in, managed in Servers. Anyone not on it is rejected after connecting, with "You are not white-listed on this server!".

Add names exactly as they appear in game, capitalization and all, then restart the server so the list is written out. If you are the one being rejected, ask the owner to check the spelling - a trailing space is enough to fail.

"I can't join"

Find the message you got, or the point where it stopped, and start there:

SymptomUsually meansFix
You are not white-listed on this serverThe name is not on the server's listOwner adds the exact name in Servers, then restarts
Outdated client / Outdated serverMinecraft versions differBoth sides move to the same version
Incompatible clientLoader or required mods differMatch the loader and the server's mod list
Unknown hostThe address is wrong, or no longer liveRe-paste it from Servers; the tunnel address changes if the server is restarted
Connection timed out / Connection refusedServer is off, still starting, or the owner's PC is asleepAsk the owner to start it and wait for the address
Failed to verify username / Invalid sessionThe server requires a real Microsoft accountSee offline names - this one you cannot fix from the client
Connection drops a second after joiningWhitelist, a mod mismatch, or a server crashCheck the server console - it names the reason
It hangs on "Connecting to the server"The tunnel or your network is blocking itRetry, try another network, ask in Discord

Still stuck? The person hosting can read the exact reason in the server Console tab - that line is worth more than guessing, so ask for it.

Offline names and premium servers

Cubeon plays with a local name, not a Microsoft sign-in. That is fine for your own servers and for anyone who joins you, but it means:

  • big public servers that require a real Minecraft account will refuse you, with a session or verification error;
  • servers that check skins and capes against Mojang will not know your Cubeon skin - see below;
  • a name that matches a real premium account is not yours to claim on those servers.

This is a deliberate trade for "pick a name and play". If a specific public server is the only thing you want, that server is the thing that wants a paid account - not the launcher.

Skins while playing

Skins and capes are a Cubeon thing. Other Cubeon players see them; a player on vanilla, or on another launcher with no skin support, sees the default model. Skin not showing walks through the cases where even a Cubeon player does not see yours.
