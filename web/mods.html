Mods, resource packs and shaders

Everything on this page follows one rule: match the version and the loader you actually launch. Get that right and the rest is mostly clicking Install.

The rule

Before you install anything

Two things have to match, or the mod will not load:

  1. The Minecraft version. A mod built for 1.20.1 does not work on 1.21 - and "1.21" and "1.21.4" are different versions to Minecraft too.
  2. The loader. Fabric mods need a Fabric instance, Forge mods need Forge, NeoForge mods need NeoForge. Vanilla cannot load mods at all.

So the first step is always: select (or create) an instance with the loader you need, on the version the mod is built for. The Mods tab uses that instance's real version and loader for its filters, which is why the download button can be unavailable for a mod you can plainly see.

Vanilla vs modded, in one line

Vanilla accepts resource packs. Mods and shaders need a modded loader, and shaders also need a shader runtime (below).

Finding a mod

Open Mods and pick the Mods content type. The search bar shows the Minecraft version, the loader and the category it is searching in, so you can see what "compatible" means before you type anything.

The filters that matter

  • Compatible only - on by default. Keep it on; it is the difference between a mod that starts and a mod that crashes your game.
  • Search all Modrinth - a button that appears when a search comes back empty. It widens the search beyond the current version and loader, so you can confirm the mod exists at all.
  • All categories - if a mod seems missing, clear the category filter. Plenty of good mods are filed somewhere unexpected.

Searching by name or by link

Type a name, or paste a Modrinth project link straight into the field. A link resolves that exact project even when your filters would normally hide it - useful when a friend sends you one. Installing from it still requires a matching Minecraft version and loader, so a link is not a way around the compatibility check.

If a full name finds nothing, Cubeon retries with shorter searches and labels those results as related matches. They are worth a look, but check the version on each one before you install it.

Mods for other Minecraft versions or loaders are still shown in a project's detail view, marked as another version. Cubeon does not hide them - it just will not download one that does not fit the selected instance.

Cubeon's catalogue is Modrinth. A mod published only on another site will not appear in these results, though a jar you already have can be added by hand.

Installing

  1. Select the instance the mod is for.
  2. Find the mod, open it, and press Download (or Install).
  3. Wait for the button to read Installed. The mod is now in the instance's Installed list.
  4. Start (or restart) the game. A mod that was installed while Minecraft was open is not in that running instance of the game.

Dependencies install with it. If a mod declares that it needs Fabric API, Cloth Config or something else, Cubeon fetches the matching build of that dependency too and tells you what it added. You do not have to hunt for them - and you should not install a different version of the same dependency by hand afterwards, because two copies of one library is a classic crash.

Cubeon keeps one build per mod per launch: if two versions of the same mod are on disk, the newest mod version that fits the running instance is the one that gets loaded.

Turning off, updating, removing

Turning a mod off

Switch it off in Installed instead of deleting it. Cubeon renames the jar rather than removing it, so switching it back on is instant and you keep the file if you want to try again.

Updating

Find the mod again and install the newer build; it replaces the old one in that instance. If a mod update breaks your game, switch the new jar off and you are back to a working setup - which is exactly why off is not the same as delete.

Removing

Remove in Installed deletes Cubeon's copy of the jar. Jars you put in the mods folder yourself are treated differently - see the next section.

Adding a jar by hand

Some mods are only published as a file. Put the jar in the folder the game reads for the instance you are about to launch:

~/.cubeon_minecraft/mods/

On Windows that is %USERPROFILE%\.cubeon_minecraft\mods\. Close Minecraft first. Cubeon rebuilds that folder at each launch from the instance you selected, so a jar you drop in is picked up for that instance and remembered as yours.

Two things Cubeon does for you here, and one it cannot:

  • Your jars are yours. Cubeon only removes jars it installed itself. Anything else stays where it is; if a launcher-managed change needs the space, your jar is moved to mods_user_backup/, never deleted.
  • The build still has to be right. The jar must be for that instance's Minecraft version and loader. Cubeon cannot rewrite a mod.
  • Dependencies are on you. A hand-added mod does not get its dependencies resolved automatically. If it needs Fabric API, install that too.

If a launcher-managed jar is locked by another running copy of the game, Cubeon stops with a "another Minecraft window is using these mods" message instead of skipping the file. Close the other window and press Play again.

Check & repair

Mods > Installed has a Check & repair button. The same button exists in the installed views for resource packs and shaders. It runs Cubeon's local Doctor in the background - no dialog, no upload - and looks for:

  • the same mod installed twice, in two different files;
  • a missing required dependency;
  • a mod built for a different loader or Minecraft version;
  • conflicts the mods declare against each other;
  • structural problems in an installed pack.

Pressing the button authorizes reversible repairs: it can fetch missing dependencies, and it renames duplicate or incompatible jars to disabled backups rather than deleting them. Re-enable anything you want back in Installed. The result appears next to the button, and hovering it explains anything it could not resolve.

Automatic checks stay quiet

Checks at launch are limited to safe launcher settings and never wait on a question; installing content can also fetch dependencies without replacing a build you already have. Nothing gets disabled without you asking for a repair.

What it cannot do: fix a bug inside a mod, or make a mod support a Minecraft version it was not built for. Those need a different mod build, which is what the "it still doesn't load" list is for.

Resource packs

Resource packs work on vanilla and modded instances, but they are still version-sensitive: a pack made for 1.16 usually looks broken on 1.21.

  1. In Mods, switch to Resource Packs and install the pack you want.
  2. In game, open Options > Resource Packs and move it to the selected column. Cubeon does not force a pack on for you.

If a pack shows up but looks wrong (missing textures, pink blocks), it is almost always built for a different Minecraft version.

Shaders

Shaders need three things at once, and the third is the one people miss:

  • a modded instance - Fabric or Forge family, not Vanilla;
  • a shader runtime for that loader, such as Iris or Oculus;
  • the shader pack itself, installed from the Shaders view.

Downloading a shader ZIP on its own changes nothing. Install the runtime first, then the pack, then choose it in game under Video Settings > Shader Packs.

Shaders are the most expensive thing you can turn on. If the frame rate collapses, drop the shader preset before you touch anything else.

Mods that don't load

What you seeUsually meansTry
Download is greyed outThe build is for another version or loaderPick the instance that matches, or choose another mod build
Game starts, mod does nothingJar is in the wrong instance, or the game was already openCheck Installed, then fully restart the game
"Missing or unsupported mod" on startA dependency is missing or the wrong versionInstall the dependency, or press Check & repair
"Duplicate mod" on startTwo jars of the same modCheck & repair renames the extra one; or switch one off
Crash naming a class or methodThe mod is built for a different Minecraft versionInstall the build for this version - see crash messages
Crash inside a mixinTwo mods change the same thing, or one is too oldSwitch off the mods added most recently, then bisect

For anything that ends in a crash, the troubleshooting guide shows where the report is and how to have Cubeon Doctor read it for you.
