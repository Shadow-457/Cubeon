ما هو Cubeon Launcher؟

Cubeon Launcher، المعروف أيضاً باسم Cubeon Minecraft Launcher، تطبيق سطح مكتب مجاني ومفتوح المصدر لـ Minecraft Java Edition على Windows وLinux. هذا هو موقع Cubeon الرسمي. ثبّت إصدارات اللعبة، وأدر النسخ المعدّلة بالمودات، وخصّص السكنات والمستلزمات التجميلية، والعب مع أصدقائك.

صفحة عن Cubeon وروابط المشروع الرسمية تشرح المنصات والترخيص وملفات تعريف اللاعبين المحلية. وCubeon مشروع منفصل عن مشغّل Cubion الذي يشبهه في الاسم.

هل تبحث عن أفضل مشغّل Minecraft لإعداداتك؟ ابدأ بإصدار اللعبة ومتطلبات حساب الخادم ومحمّل المودات. يشرح دليلنا مدى ملاءمة Cubeon لك، وما يجب التحقق منه قبل التنزيل، وكيفية تقييم ادعاءات معدل الإطارات.

ثبّت مشغّل Minecraft، أو أضف مودات وحزم موارد وشيدرات، أو جهّز حزمة مودات. استخدم الأدلة للعب Minecraft مع الأصدقاء ولحل مشكلة تعطل. يوجد مستودع Cubeon الرسمي وسجل الإصدارات على GitHub.

Cubeon Launcher مشغّل سطح مكتب مجاني مفتوح المصدر بترخيص Apache 2.0 لـ Minecraft Java Edition على Windows وLinux. يدير إصدارات اللعبة والنسخ المعدّلة بالمودات والمودات وحزم المودات والسكنات والمستلزمات التجميلية والأصدقاء والخوادم المحلية. الموقع الرسمي هو www.ylet.online ومستودع المصدر هو Shadow-457/Cubeon على GitHub. اقرأ حقائق المشروع الرسمية بشأن ملفات التعريف المدعومة والتنزيلات والقيود.

قد تقترح محركات البحث اسم Cubion المشابه في الكتابة عندما تبحث عن Cubeon. اسم هذا المشروع هو Cubeon Launcher، بحرف e. للعثور على هذا المشغّل، ابحث عن Cubeon Minecraft Launcher أو استخدم الموقع الرسمي www.ylet.online ومستودع Shadow-457/Cubeon على GitHub.

يشغّل Cubeon لعبة Minecraft Java Edition بنسخ Vanilla أو Fabric أو Quilt أو Forge أو NeoForge. ولا يشغّل Bedrock Edition. يجب أن تتوافق المودات مع إصدار Minecraft والمُحمّل المحددين؛ كما تحتاج الشيدرات إلى إعداد متوافق مثل Iris. راجع دليل المودات والشيدرات.

يناسبك Cubeon إذا أردت مشغّلًا مجانيًا مفتوح المصدر لإصدار Java مع محمّلات مودات متوافقة ومودات وحزم مودات وسكنات وأصدقاء على Windows أو Linux. يستخدم ملفات تعريف محلية/غير متصلة، ولا يوفّر تسجيل الدخول بحساب Microsoft أو تشغيل إصدار Bedrock. يعتمد الخيار الأفضل على إصدار لعبتك ومتطلبات الخادم والمودات؛ استخدم دليل مشغّل Minecraft للتحقق من احتياجاتك قبل التنزيل.

يستخدم Cubeon ملفات تعريف لاعبين محلية/دون اتصال: اختر اسماً من ثلاثة إلى ستة عشر حرفاً. ولا يوفّر تسجيل الدخول بحساب Microsoft. الخوادم التي تتطلب مصادقة Microsoft لا يمكنها قبول ملفات التعريف هذه؛ راجع دليل اللعب الجماعي.

أضف أصدقاءك باسمهم في Cubeon، وسيحتفظ المشغّل بالمحادثة ويعرض المتصلين وما يلعبونه. للعب معًا، انضموا إلى خادم Minecraft نفسه باستخدام العنوان الذي يقدّمه مالكه. استخدموا إصدار Minecraft والمودات المطلوبة للخادم، وتأكدوا من أنه يقبل ملفات التعريف المحلية أو غير المتصلة.
