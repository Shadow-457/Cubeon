عن Cubeon Launcher

حقائق المشروع الرسمية والتنزيلات والشيفرة المصدرية لـ Cubeon Minecraft Launcher.

ما هو Cubeon؟

Cubeon Launcher، المعروف أيضاً باسم Cubeon Minecraft Launcher، مشغّل سطح مكتب مجاني ومفتوح المصدر لـ Minecraft Java Edition. يدير إصدارات اللعبة والنسخ المعدّلة بالمودات والمودات وحزم المودات والسكنات والمستلزمات التجميلية والأصدقاء والخوادم المحلية في تطبيق واحد.

هذا موقع Cubeon الرسمي، www.ylet.online. ومستودع المصدر الرسمي هو Shadow-457/Cubeon على GitHub. وCubeon مشروع منفصل عن مشغّل Cubion الذي يشبهه في الاسم. استخدم هذه الروابط الرسمية للتعرّف على Cubeon عند البحث عن التنزيلات أو الدعم.

حقائق المشروع

  • المنتج: Cubeon Launcher، تطبيق سطح مكتب لـ Minecraft Java Edition.
  • المنصات: Windows 10 و11 وLinux وmacOS. راجع أصول الإصدار لمعرفة البنية المتاحة.
  • السعر: المشغّل مجاني.
  • ترخيص المصدر: Apache License 2.0. وتحتفظ المكوّنات الخارجية المضمّنة بتراخيصها الخاصة.
  • الشيفرة المصدرية: Python وFlet لتطبيق سطح المكتب، وJava لعميل Minecraft المرافق.
  • ملفات تعريف اللاعبين: أسماء محلية/دون اتصال؛ ولا يوفّر Cubeon تسجيل الدخول بحساب Microsoft.
  • إصدار اللعبة: Minecraft Java Edition. ولا يشغّل Cubeon إصدار Bedrock.

التنزيلات والإصدارات

استخدم صفحة التنزيل الرسمية لخيارات المنصات أو أحدث إصدار مستقر على GitHub لملفاته وملاحظات الإصدار. يستخدم Windows مثبّت Setup.exe. ولـ Linux نسخة AppImage ومثبّت وحزمة Debian/Ubuntu. وتوفّر إصدارات macOS حزمة تطبيق في Cubeon-macOS.zip.

كل الإصدارات تتضمن أيضاً نسخاً موسومة كإصدارات أولية لاختبار النسخة التجريبية. تحقق من وسم الإصدار قبل التنزيل. ولا تتطلب النسخ الجاهزة Python؛ وتعليمات الإعداد من المصدر موجودة في المستودع.

المودات وملفات التعريف واللعب معاً

يدعم Cubeon إعدادات Vanilla وFabric وQuilt وForge وNeoForge. ويجب أن يتوافق المود مع إصدار Minecraft والمُحمّل في النسخة التي تشغّلها. ويقبل Vanilla حزم الموارد، بينما تحتاج المودات والشيدرات إلى إعداد متوافق معدّل بالمودات.

يتصفّح المشغّل المودات عبر Modrinth، ويدير حزم المودات، ويتيح لك استيراد المحتوى المحلي. ويشرح دليل المودات والشيدرات التوافق والاعتماديات؛ ويغطي دليل حزم المودات الحزم والاستيراد.

تشمل ميزات الأصدقاء محادثة المشغّل وحالة الاتصال. ويمكن لأدوات الخادم المحلي مشاركة عالم عبر نفق عام. ولا تستطيع ملفات تعريف اللاعبين المحلية الانضمام إلى الخوادم التي تتطلب مصادقة Microsoft. اقرأ قيود ملفات تعريف اللعب الجماعي قبل اختيار خادم.

السكنات والعباءات ورفقاء الكتف والمستلزمات التجميلية للظهر موثّقة في دليل المستلزمات التجميلية. ويعتمد دعم الميزات داخل اللعبة على إصدار اللعبة والمُحمّل والعميل المرافق.
