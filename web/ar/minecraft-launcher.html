ابدأ بإصدار Minecraft وحسابك

يثبّت مشغّل Minecraft اللعبة ويشغّلها ويختار الإصدارات ويضبط كيفية تشغيلها. تدير بعض المشغّلات أيضًا المودات وحزم المودات والنسخ المنفصلة. لا يتضمن المشغّل المجاني ترخيص Minecraft.

Cubeon Launcher مشغّل Minecraft Java Edition مجاني ومفتوح المصدر لـ Windows وLinux. يجمع محمّلات المودات المتوافقة والمودات وحزم المودات والسكنات والأصدقاء في تطبيق سطح مكتب واحد. اقرأ حقائق مشروع Cubeon الرسمية لمعرفة ترخيص المصدر وملفات التعريف المدعومة.

تحقق من خادمك أولًا. يستخدم Cubeon ملفات تعريف محلية/غير متصلة ولا يوفّر تسجيل الدخول بحساب Microsoft. لا تقبل الخوادم التي تتطلب مصادقة Microsoft هذه الملفات. إذا كان تسجيل الدخول هذا أو إصدار Bedrock ضروريًا لك، فتحقق من مشغّل Minecraft الرسمي وحق حسابك في اللعبة.

اختيار مشغّل Minecraft للمودات وحزم المودات

اسم محمّل المودات وحده لا يكفي. قد لا يعمل مود Fabric لإصدار معين من Minecraft مع إصدار آخر، ولا يمكن تثبيت نسخة Forge ببساطة داخل نسخة Fabric. ابدأ بالإصدار ومحمّل المودات اللذين يحددهما مؤلف المود أو الحزمة.

يمكن لـ Cubeon تثبيت محمّلات المودات المدعومة وتصفح المودات وحزم الموارد والشيدرز. تحتاج المودات إلى نسخ معدّلة متوافقة؛ وتقبل Vanilla حزم الموارد. تحتاج الشيدرز أيضًا إلى إعداد متوافق مثل Iris. يغطي دليل المودات والشيدرز التبعيات والتثبيت والإصلاح.

للحصول على حزمة كاملة، اتبع دليل حزم المودات واحتفظ بإصدار اللعبة الموصى به. تساعد النسخ المنفصلة على تنظيم الإعدادات، لكن المحتوى المشترك يظل بحاجة إلى فحوص التوافق. انسخ ملفات الحفظ احتياطيًا قبل تغيير إصدار لعبة عالمك أو حزمة موداته.

هل يحسّن مشغّل Minecraft معدل الإطارات؟

يمكن للمشغّل ضبط Java والذاكرة ومودات الأداء المتوافقة. تظل بطاقة الرسومات والمعالج وتعريفات الرسومات والعالم ومسافة الرؤية والشيدرز والمودات المثبتة عوامل أساسية في النتيجة. لا يضمن اسم المشغّل معدل إطارات أعلى على كل جهاز.

يوفّر Cubeon إعدادات للذاكرة وتجهيزًا لمودات الأداء المتوافقة. ابدأ بـ دليل تعزيز معدل الإطارات. قد تؤدي زيادة RAM دون التحقق من الذاكرة المتاحة في الجهاز إلى أداء أسوأ.

عند مقارنة المشغّلات، ثبّت إصدار اللعبة والعالم والمودات وJava والذاكرة ومسافة الرؤية وإعدادات الرسومات وVSync وحد الإطارات. قيّم انتظام زمن الإطار إلى جانب متوسط معدل الإطارات. تعرض صفحة اختبارات أداء Cubeon ظروف القياسات المنشورة وحدودها.

  1. تأكد أنك تلعب إصدار Java وأن خادمك يقبل ملفات التعريف المحلية/غير المتصلة.
