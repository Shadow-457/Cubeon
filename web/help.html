Help & questions

Short, plain answers. If the thing you're stuck on isn't here, send us a message - it's a small project and a real person reads it.

Getting started

  1. Download Cubeon for your computer and open it - the download page explains which file suits you.
  2. Pick a name. Three to sixteen characters. No account, no email, no password.
  3. Choose a Minecraft version and press play. The first launch takes a few minutes because the game downloads; after that it starts quickly.
  4. Add your friends by their Cubeon name and they'll appear in your list.

Playing together

Add friends by their Cubeon name and the launcher keeps the conversation: who's online, what version each of them is playing, and messages you can come back to. Cubeon also marks its players in Minecraft's own player list (hold Tab in game), so you can tell at a glance who else is on Cubeon.

To share an actual world, open Servers, install a server for the version you picked, and hand out the free public address it gives you. Set a join password and only the people you tell can get in. Nobody has to change anything on their computer, and nobody has to pay for a server.

Skins, capes, mods and worlds

Set a skin and a cape in the launcher and other Cubeon players see them wherever you play together. Mods, resource packs and ready-made modpacks install per version, so one messy setup can't spoil your clean one.

If something goes wrong

Open Cubeon Doctor to check a crash log and follow a visual troubleshooting guide. In the launcher, the crash report’s Doctor button brings your log automatically.

The game won't start

Minecraft needs Java. Cubeon uses a Java it finds on your computer when it's new enough, and if there isn't one it offers to download a free one for you - so usually there's nothing to install yourself. If a launch still fails, you can install Java free from adoptium.net, or paste the path to a Java you already have in Settings > Java, and try again.

Your computer warns you about the file

That happens with small independent apps, because they aren't signed by a big company. Signing them properly would cost more than 359€ a year, so we don't. On Windows, choose Keep, then More info, then Run anyway. On Linux, if it asks about permissions, allow it to run.

It feels slow, or the frame rate dips

Cubeon's FPS boost is on by default. It installs Sodium and five companion mods into the profile you launch and sets the graphics options that cost frames to their fast values; turning it off restores vanilla graphics on the next launch, and the switch is in the Play menu. If it's already on and the game still stutters, lower the render distance first - that is almost always the biggest single setting. The benchmarks page shows what the boost is worth on a real PC, measured against two other launchers.

A friend can't join your server

Check you gave them the exact address from Servers, and the join password if you set one. They should be on the newest Cubeon - if in doubt, download the latest from the download page - and on the same Minecraft version as the server.

You can't find a friend by name

They need to have opened Cubeon at least once before their name exists. Names are first come, first served.

Something else entirely

Tell us what happened at hamza.457.shahbaz@gmail.com, and what you were doing at the time. Cubeon also leaves a small note of what went wrong in its own folder inside your user folder (it's called .cubeon_launcher) - sending that along makes a fix much faster.
