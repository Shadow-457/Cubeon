Start here

The three minutes version

  1. Get the app. Download Cubeon for Windows or Linux, open it, and pick a name - no account, no email, no password.
  2. Pick a version and press Play. The first launch downloads the game, which takes a few minutes. After that it starts in seconds.
  3. Add your friends by their Cubeon name, or install a mod, a pack or nothing at all. Everything else on this page is a guide for when you want to go further.
Just want to play, nothing added?

You do not need any of the mod guides. Choose the version your friends play, press Play, and read playing together when you want to host a world.

Recovery mods

Deleted a mod? Download the Cubeon Client build for the Minecraft version and loader shown on your instance card.

  1. Close Minecraft and select the instance you want to repair.
  2. Download the matching Cubeon Client JAR below.
  3. Open Mods → Import mods, select the downloaded JAR, and install it. Then start Minecraft again.

Keep one Cubeon Client JAR per instance. Minecraft 1.20.0 uses the 1.20 build. Fabric and Quilt also need Fabric API for the HUD.

When none of this fits

Open Cubeon Doctor and drop the crash log in - it reads the report and writes a numbered list of things to try, without an account. The crash window in the launcher has a Doctor button that fills it in for you.

If it is not a crash, ask a person: the Discord is the quickest answer, and hamza.457.shahbaz@gmail.com reaches the developer. Include your operating system, the Cubeon version, and what you were doing when it broke - the files guide says which log to send and what to blank out first.
