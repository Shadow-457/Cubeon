About Cubeon Launcher

The official project facts, downloads and source code for Cubeon Minecraft Launcher.

What is Cubeon?

Cubeon Launcher, also called Cubeon Minecraft Launcher, is a free, open-source desktop launcher for Minecraft Java Edition. It manages game versions, modded instances, mods, modpacks, skins, cosmetics, friends and local servers in one app.

This is the official Cubeon website, www.ylet.online. The official source repository is Shadow-457/Cubeon on GitHub. Cubeon is a separate project from the similarly named Cubion launcher. Use these official links to identify Cubeon when looking for downloads or support.

Project facts

  • Product: Cubeon Launcher, a desktop app for Minecraft Java Edition.
  • Platforms: Windows 10 and 11, Linux and macOS. See the release assets for the available architecture.
  • Price: the launcher is free.
  • Source license: Apache License 2.0. Bundled third-party components keep their own licenses.
  • Source code: Python and Flet for the desktop launcher, Java for the companion Minecraft client.
  • Player profiles: local/offline names; Cubeon does not provide Microsoft account sign-in.
  • Game edition: Minecraft Java Edition. Cubeon does not launch Bedrock Edition.

Downloads and releases

Use the official download page for platform options or the latest stable GitHub release for its files and release notes. Windows uses the Setup.exe installer. Linux has an AppImage, a setup installer and a Debian/Ubuntu package. macOS releases provide an app bundle in Cubeon-macOS.zip.

All releases also includes versions marked as prereleases for beta testing. Check the release label before downloading. Packaged builds do not require Python; source setup instructions are in the repository.

Mods, profiles and playing together

Cubeon supports Vanilla, Fabric, Quilt, Forge and NeoForge configurations. A mod must match the Minecraft version and loader of the instance you launch. Vanilla accepts resource packs, while mods and shaders need a compatible modded setup.

The launcher browses mods through Modrinth, manages modpacks, and lets you import local content. The mods and shaders guide explains compatibility and dependencies; the modpacks guide covers packs and imports.

Friends features include launcher chat and presence. Local server tools can share a world through a public tunnel. Local player profiles cannot join servers that require Microsoft authentication. Read the multiplayer profile limitations before choosing a server.

Skins, capes, shoulder companions and back cosmetics are documented in the cosmetics guide. In-game feature support depends on the game version, loader and companion client.
