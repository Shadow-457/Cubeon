Help

Getting started

  1. Download Cubeon for your computer and open it — the download page explains which file suits you.
  2. Pick a name. Three to sixteen characters. No account, no email, no password.
  3. Choose a Minecraft version and press play. The first launch takes a few minutes because the game downloads; after that it starts quickly.
  4. Add your friends by their Cubeon name and they’ll appear in your list.

Playing together

Add friends by their Cubeon name and the launcher keeps the conversation: who’s online, what version each of them is playing, and messages you can come back to. Cubeon also marks its players in Minecraft’s own player list (hold Tab in game), so you can tell at a glance who else is on Cubeon.

To share an actual world, open Servers, install a server for the version you picked, and hand out the free public address it gives you. Set a join password and only the people you tell can get in. Nobody has to change anything on their computer, and nobody has to pay for a server.

Skins, capes, mods and worlds

Set a skin and a cape in the launcher and other Cubeon players see them wherever you play together. Mods, resource packs and ready-made modpacks install per version, so one messy setup can’t spoil your clean one.

If something goes wrong

The game won’t start

Minecraft needs Java. Cubeon uses a Java it finds on your computer when it’s new enough, and if there isn’t one it offers to download a free one for you — so usually there’s nothing to install yourself. If a launch still fails, you can install Java free from adoptium.net, or paste the path to a Java you already have in Settings > Java, and try again.

Your computer warns you about the file

That happens with small independent apps, because they aren’t signed by a big company. Signing them properly would cost more than 359€ a year, so we don’t. On Windows, choose Keep, then More info, then Run anyway. On Linux, if it asks about permissions, allow it to run.

It feels slow, or the frame rate dips

Cubeon’s FPS boost is on by default. It installs Sodium and five companion mods into the profile you launch and sets the graphics options that cost frames to their fast values; turning it off restores vanilla graphics on the next launch, and the switch is in the Play menu. If it’s already on and the game still stutters, lower the render distance first — that is almost always the biggest single setting. The benchmarks section shows what the boost is worth on a real PC, measured against two other launchers.

A friend can’t join your server

Check you gave them the exact address from Servers, and the join password if you set one. They should be on the newest Cubeon — if in doubt, download the latest from the download page — and on the same Minecraft version as the server.

You can’t find a friend by name

They need to have opened Cubeon at least once before their name exists. Names are first come, first served.

Something else entirely

Tell us what happened at hamza.457.shahbaz@gmail.com, and what you were doing at the time. Cubeon also leaves a small note of what went wrong in its own folder inside your user folder (it’s called .cubeon_launcher) — sending that along makes a fix much faster.

How it was measured

Each launcher was recorded playing Minecraft 1.21.11 on the same PC, in three separate one-minute runs. The frame rate was then counted frame by frame out of the screen recordings — one sample per second of video — rather than trusting each launcher’s own FPS display. “In game” means roughly 28–32 seconds of actual gameplay per launcher; “menu” is the pause screen.

All three launched as-is

Nothing was added or changed by hand for any of them. On the SKLauncher side there was no Sodium and no mods at all — plain vanilla — so it is being compared against launchers that ship Sodium. That is the honest reading of its numbers: a big part of the gap is the performance mods Cubeon installs for you, not the launcher’s own code.

Cubeon’s FPS boost is on by default, and it is the reason Cubeon ships Sodium. The switch installs Sodium plus five companion mods (Lithium, ImmediatelyFast, Entity Culling, FerriteCore and More Culling) into the profile you launch, and sets the graphics options that cost frames to their fast values. Turn it off and the next launch restores vanilla graphics — the switch is in the Play menu, and it says which way it is set.

  • Cubeon was fastest in game — about 206 FPS on average, roughly 35% above FastClient (152) and 74% above SKLauncher (119).
  • Cubeon also had the best worst case. Its lowest in-game second was 102 FPS, against 37 (FastClient) and 33 (SKLauncher). The average is the headline; this is the one you feel.
  • FastClient held up best between menu and game — only about an 8% drop, where Cubeon and SKLauncher each lost about 19%. It is the most consistent of the three, just not the fastest.
  • SKLauncher looked frame-capped on the pause menu at about 147 FPS, and was the slowest in game with the deepest dips.

What this test is not

A comparison like this is easy to make flattering. Here is everything that weakens it, in the order it matters.

  • Not a lab test. Each launcher was recorded in a different spot in the world, so the comparison is indicative rather than controlled. The same world, the same camera path and several runs per launcher would be a stronger test.
  • F3 was on for Cubeon and SKLauncher, off for FastClient (it uses its own FPS display). The debug screen costs a little FPS, so this slightly favours FastClient — and the gap is still large.
  • Nothing was equalised. SKLauncher ran vanilla with no Sodium and no mods, and its own defaults differed (fancy clouds, RGSS filtering, where Cubeon was on fast clouds with no filtering). Its numbers say “a vanilla install on this PC”, not “this launcher’s best”.
  • FastClient’s digits are blurry in the video. A few of its menu readings may be off by about 5 FPS. Every reading was checked by eye, twice.
What we would like to do next

Run all three with identical settings, the same world and the same camera path, several times each, and publish that alongside this. If you want to help with a recording on your own hardware, the Discord is the place — more machines make this more useful.

You can check this yourself

1

Install and pick a version

Install Cubeon and choose the same Minecraft version the test used (1.21.11), or whatever you normally play. First launch downloads the game, so give it a minute.

2

Leave FPS boost on

It is on by default. It installs Sodium and the five companion mods into the profile and sets the graphics options that cost frames to their fast values.

3

Watch the counter

Press F3 in game for Minecraft’s own FPS line, play for a minute, and compare it with your usual launcher. Same world, same settings, same time of day is the fair way.

Fairer on both sides

Turn FPS boost on for Cubeon and give the other launcher its own performance mods before you judge it. A vanilla install against a boosted one mostly measures the mods, which is exactly what the caveats above say about SKLauncher.
