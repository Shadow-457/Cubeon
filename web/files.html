Files, folders and backups

Two folders in your user folder hold everything Cubeon knows: one for the launcher, one for the game. Once you know which is which, deleting the safe things becomes obvious.

The map

Where things live

~ means your home folder. On Windows that is %USERPROFILE% - the folder with your name on it, not Program Files.

FolderWhat is in it
~/.cubeon_launcher/ The launcher itself: settings, your local identity, caches, downloaded Java runtimes, your skin and cape files, and the launcher log.
~/.cubeon_minecraft/ The game: installed versions, instances, mods, resource packs, shaders, worlds, screenshots and crash reports.

Both are yours. Nothing in them needs an installer, and copying them to another machine carries everything across - see moving to a new PC.

Cubeon keeps its game files private

It uses its own .cubeon_minecraft folder rather than the standard .minecraft one on purpose: another launcher updating or cleaning its files cannot then wipe a version Cubeon is using, and Cubeon cannot change what another launcher reads.

Inside an instance

Every instance plays in its own folder:

~/.cubeon_minecraft/instances/<instance>/

These are real, separate copies per instance:

  • saves/ - your worlds
  • config/ - mod configs
  • options.txt - video settings, keybinds, language
  • servers.dat - your server list

These are shared with every other instance, and appear in the folder as links to one copy:

  • mods/, resourcepacks/, shaderpacks/
  • CustomSkinLoader/ - the skin setup
  • screenshots/ and crash-reports/

So: changing a video setting in one instance does not change it in another, but installing a mod applies everywhere. That is the intended split - a world should be private, a mod library should not be downloaded twice.

Deleting an instance does not delete its saves/ folder. If the world matters, copy that folder out first.

Mods and content folders

Two layers, and it helps to know which is which before you drag a jar anywhere:

  • ~/.cubeon_minecraft/mods/, resourcepacks/, shaderpacks/ - what the game reads right now. Cubeon rebuilds these at launch from the instance you selected, so treat them as a staging area.
  • ~/.cubeon_minecraft/global_mods/ and global_content/ - the real library: one clearly named copy of each mod, pack and shader, shared by every instance.

A jar you drop into mods/ by hand is adopted for the instance you are playing and is never deleted - it is yours, not Cubeon's. See adding a jar by hand.

If Cubeon has to move a jar out of the way, it puts it in ~/.cubeon_minecraft/mods_user_backup/ rather than destroying it. Files a modpack replaces are backed up under .cubeon-override-backup/ with a timestamp.

Logs and crash reports

FileWhat it tells you
~/.cubeon_launcher/cubeon.logThe launcher's own log: startup, downloads, installs and launcher errors. Send this one when the app itself misbehaves.
~/.cubeon_minecraft/crash-reports/Minecraft's crash reports, one file per crash. Send the newest one when the game crashes.
~/.cubeon_minecraft/logs/Minecraft's normal game log, including the latest.log from the last run. Useful when the game closed without a crash report.

Before sending anything, open it in a text editor and remove what you would not post publicly: your name, your home folder path, private server addresses, and anything that looks like a key or token. The Crash Doctor also redacts an excerpt for you, but it says plainly that automatic redaction cannot catch everything.

Which one to send: launcher closed on its own → cubeon.log. Game crashed → the newest file in crash-reports. Game closed with no message → logs/latest.log.

Backups

Launcher backups

Settings > Backups saves your launcher configuration and keeps a history you can restore from. It is the safety net for settings - RAM, Java path, language, cosmetic choices - and it means a bad change costs one button, not a reinstall.

World backups are yours to make

Cubeon does not copy your worlds on a schedule. A world lives in one folder; back it up by copying that folder somewhere else while the game is closed:

~/.cubeon_minecraft/instances/<instance>/saves/<world>/

Copy the whole world folder, not just level.dat. To restore, close the game and put the folder back into saves/.

Mods and packs

You do not need to back these up to keep them - they are re-downloadable and the global libraries hold one copy already. Back up a hand-edited config if you spent time on it.

Moving to a new PC

  1. Close Cubeon completely, and close Minecraft.
  2. Copy ~/.cubeon_launcher/ and ~/.cubeon_minecraft/ to the same paths on the new machine.
  3. Install Cubeon there and open it.
  4. Check Settings > Java: a saved path to a Java that only existed on the old PC will not work. Clear it and let Cubeon manage Java again.

Your Cubeon name travels with .cubeon_launcher, which is what keeps friends, skins and servers recognising you. Keep that folder private - it is identity, not just settings.

Before you copy, know that runtimes/ (downloaded Java) and caches are the bulky parts. Skipping them is safe: Cubeon downloads what it needs again.

Resetting or uninstalling

Uninstalling the app and deleting your data are two different things, and only one of them is what you usually want.

  • Uninstall the app - removes the program. Your settings, name, worlds and mods stay exactly where they are, ready for the next install.
  • Delete ~/.cubeon_launcher/ - forgets your name, skins, capes, settings and caches. This is the "start completely fresh" button, and friends will no longer recognise the old name as you.
  • Delete ~/.cubeon_minecraft/ - removes installed versions, worlds, mods and packs. Everything in it can be re-downloaded except your worlds, so copy saves/ out first.

Never delete either folder while Cubeon or Minecraft is running: the app will write files back into the half-deleted folder, and that is how settings get corrupted. Close everything first, then delete.

If you only want to fix something, you rarely need either. Troubleshooting starts with the cheap checks, and Settings > Java plus Check & repair fix most of what a reset would.
