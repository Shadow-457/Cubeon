# Launcher icons

User-supplied SVG artwork for launcher navigation and content selection:

- `mods.svg`: Mods sidebar tile and content selector.
- `modpacks.svg`: Modpacks content selector.
- `resource-packs.svg`: Resource Packs content selector.
- `shaders.svg`: Shaders content selector.
- `play.svg`: Play sidebar tile.
- `chat.svg`: Chat sidebar tile when chat is available.
- `cosmetics.svg`: Cosmetics sidebar tile.
- `stats.svg`: Stats sidebar tile.
- `servers.svg`: Servers sidebar tile.
- `settings.svg`: Pinned Settings sidebar tile.

The supplied files stay unchanged. Images retain their original colors; the
sidebar uses opacity for hover/selection, and the content selector styles its
button and label. All images keep fixed dimensions and are bundled for offline use.
