# Default Steve

`steve.png` is Minecraft Java Edition's classic-arm Steve texture, extracted
unchanged from Minecraft 1.20.1 at
`assets/minecraft/textures/entity/player/wide/steve.png`.
Minecraft artwork belongs to Mojang/Microsoft; this is not original Cubeon art.

`steve-preview.png` is its front-view card preview, generated with
`cubeon.skins.render_local_skin_preview(..., scale=8, src_path="assets/skins/steve.png")`.
The shared skin fallback and CustomSkinLoader default use the same texture.
