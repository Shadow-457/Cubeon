# Catalogue provider icons

Modrinth and CurseForge SVGs from [Simple Icons](https://github.com/simple-icons/simple-icons),
retrieved 2026-11-16. Simple Icons publishes these paths under CC0-1.0.
The only change is each provider's brand fill: `#1BD96A` and `#F16436`.
Brand names and trademarks belong to their respective owners.

- [Modrinth source](https://github.com/simple-icons/simple-icons/blob/develop/icons/modrinth.svg)
- [CurseForge source](https://github.com/simple-icons/simple-icons/blob/develop/icons/curseforge.svg)

These bundled assets let Mods show source icons offline without CDN requests.
