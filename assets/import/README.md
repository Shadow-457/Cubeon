# Import illustration

`launcher-folder.svg` is an original Cubeon illustration of an installed game
folder. It is covered by the repository license. It is not FastClient's logo
and is not derived from FastClient artwork. The destination uses `../cube.svg`.

FastClient is named only to identify the supported import source. Its official
[terms, section 11](https://fastclient.net/terms), checked 2026-11-17, reserve
logos and other artwork and require written permission for their use. No such
permission is recorded here; do not substitute their logo without verifying it.
