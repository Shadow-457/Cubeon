# Play update artwork

Official Minecraft promotional covers and desktop wallpapers, bundled for immediate offline display.
WebP copies use quality 92 with no enlargement; desktop wallpapers are at most 1920×1080.
Patch releases share the appropriate update/drop cover. Legacy versions and unrecognized release
IDs share the official Java Edition cover, without claiming a separate illustration for every old update.
