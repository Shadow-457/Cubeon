# Launcher background artwork

Title-free Minecraft wallpapers and official release screenshots, bundled for immediate offline display.
All covers come from Minecraft's official Collectibles page or Minecraft.net release articles.
Most covers are 2560 x 1440, without enlargement. Bats and Pots is 3840 x 2160;
Bundles of Bravery is 1920 x 1080. Trails & Tales uses a 2058 x 1440 official wallpaper
cropped to 2058 x 1020 to remove its logo and title.
The Bats and Pots image uses the Contentful image CDN linked in Mojang's release article.
Patch releases share the appropriate update/drop cover. Legacy versions and unrecognized release
IDs share the official Java Edition cover, without claiming a separate illustration for every old update.

The `blurred/` directory contains pre-blurred copies for fixed glass chrome and feature-page backgrounds.
